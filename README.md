# 학교 탈출

퀴즈를 풀고 아이템을 모아 학교를 탈출하는 공포 게임

## 프로젝트 실행 방법

### `docker compose up`

시연 발표를 위해 정답 확인이 필요하므로 반드시 포그라운드로 실행해주세요.

## 프로젝트 구조


```java
escape-school/
│
├─ backend/
│   ├─ main.py
│   └─ Dockerfile
│
├─ frontend/
│   ├─ package.json
│   ├─ src/…
│   └─ Dockerfile
│
└─ docker-compose.yml

```

## 프로젝트 환경

```
* 프로그래밍 언어
  - Python 3.11
  - JavaScript
* 프레임워크 / 라이브러리
  - React: v19.2.0
* 컨테이너 & 배포
  - Docker 
  - Docker Compose
* 빌드 & 패키지 관리
  - Python: pip
  - JavaScript: npm
```
